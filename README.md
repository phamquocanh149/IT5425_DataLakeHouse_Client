# IT5425_DataLakeHouse_Client

Python client thu thập và truyền dữ liệu khí hậu tới Climate Data Lake Server.

Mã nguồn và hướng dẫn cài đặt: [climate-collector](climate-collector/README.md).

Sau khi clone, tạo môi trường Python 3.11/3.12 trong `climate-collector`, cài
`requirements.txt`, sao chép `.env.example` thành `.env` và điền URL/API key của Server.
Không commit credentials hoặc dữ liệu runtime.
